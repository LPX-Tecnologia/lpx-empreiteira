# LPX Empreiteira – Sistema Web

Sistema completo para empreiteira: exibição de serviços, solicitação de orçamentos, vagas de emprego e painel administrativo.

## 🚀 Funcionalidades

- Página inicial moderna com animações
- Catálogo de serviços com formulário de orçamento
- Página de vagas com formulário de candidatura
- Página de contato com mapa
- Painel administrativo que exibe dados salvos no localStorage
- Logo animada "LPX"
- Botão flutuante do WhatsApp
- Totalmente responsivo

## 🛠️ Tecnologias

- HTML5, CSS3, JavaScript (Vanilla)
- Bootstrap 5
- Animate.css
- AOS (Animate On Scroll)
- Font Awesome
- Google Fonts
